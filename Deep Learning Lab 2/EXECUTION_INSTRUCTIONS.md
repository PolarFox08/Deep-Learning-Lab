# Execution Instructions

To run the notebooks in this directory, follow these steps:

## 1. Clone the Repository and Navigate to the Lab Directory

```bash
git clone https://github.com/PolarFox08/Deep-Learning-Lab.git
cd Deep-Learning-Lab/"Deep Learning Lab 2"
```

## 2. Install Dependencies

Install the required packages using pip:

```bash
pip install -r requirements.txt
```

## 3. Run the Jupyter Notebooks

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open and execute either of the following notebooks:
* `DL2_MLP_Fashion_MNIST.ipynb` (Multi-Layer Perceptron for Fashion-MNIST Classification)
* `DL_Lab_2_XOR_gate.ipynb` (Multi-Layer Perceptron for XOR Gate)
