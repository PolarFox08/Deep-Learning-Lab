# Execution Instructions

To run the notebook in this directory, follow these steps:

## 1. Clone the Repository and Navigate to the Lab Directory

```bash
git clone https://github.com/PolarFox08/Deep-Learning-Lab.git
cd Deep-Learning-Lab/"Deep Learning Lab 3"
```

## 2. Install Dependencies

Install the required packages using pip:

```bash
pip install -r requirements.txt
```

## 3. Download the Dataset

Download the CIFAR-10 python archive and place the extracted `cifar-10-batches-py` folder where the notebook expects it. See `DATASET_INFO.md` for details.

## 4. Run the Jupyter Notebook

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open and execute:
* `DL_Lab_3_pytorch.ipynb` (Convolutional Neural Networks for CIFAR-10 Image Classification)
